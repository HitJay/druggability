# 💊 Druggability – 靶点成药性评估

> 靶点成药性（druggability）评估与建模

## 📝 项目简介

本项目旨在构建靶点成药性评估与建模系统，支持：

- 靶点成药性特征分析
- 成药性评分与预测建模
- 自动化评估报告生成

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://github.com/HitJay/druggability.git
cd druggability

# 创建 conda 环境（待配置）
# conda env create -f environment.yml
```
