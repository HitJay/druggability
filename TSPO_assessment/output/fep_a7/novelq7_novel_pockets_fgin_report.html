4. Caveats

  • Computational scores are supporting evidence, not proof of binding; only measured data can enter Tier 1–2 of the target assessment.
  • TI here annihilates side chains at the docked/relaxed geometry (computational alanine scanning). It answers "does the ligand use this side chain", not absolute affinity; ε/q scaling only, σ fixed.
  • 12 anchors in the first parallel sweep silently returned exact-zero windows (a mixed-precision CUDA artifact observed under 4-GPU contention). All suspect jobs were re-run sequentially in double precision; every reported number passes the non-zero-window test in tests/test_novelq7_dataset.py.
  • MD is 250 ps per pocket — pose-stability timescale only, not residence time or binding kinetics.
  • IE/TI share the no-desolvation limitation: charged contacts are overstated; ranking use only.
  • Residue numbering follows the pdbfixer-processed complexes (chain-suffixed), self-consistent within this round.
