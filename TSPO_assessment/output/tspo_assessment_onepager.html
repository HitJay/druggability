Headline findings computational — supporting evidence, not proof of binding

1CAR (NR1I3) is the #2 PK11195 target. ChEMBL sub-µM antagonism + PubChem + SwissTarget 0.888 + docking 1XVP −10.89 kcal/mol + Boltz-2 fold reproduction (5.65 Å RMSD). All TSPO PET-tracer safety reads must include the CAR/PXR nuclear-receptor axis (DILI, DDI).
2New pocket: TSPO dimer interface (4RYI_p26). Orthosteric overlap <30%; emapunil −7.64 / FGIN −9.17, both MD-stable, TI-confirmed on both ligands (+7.7 / +7.6 kJ/mol). Mutation path ready: TSPO dimerization assay × LEU58 mutant.
3SER196 (GABA-A TMD pocket 6X3X_p78): ligand-independent strong anchor. Two chemically unrelated ligands independently lose ~+20 kJ/mol on annihilation — the top mutagenesis candidate of the round.
