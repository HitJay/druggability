2 · Layer comparison — both computational layers vs paper EC50

Headline findings (45-compound Boltz-2 run, 2026-08-05)

  • Boltz-2 affinity probability vs paper EC50: no correlation (Pearson r = -0.044 vs log10 EC50, n = 41; Vina 8Z8A score r = -0.117). Both computational layers fail to rank potency across the series — consistent with the project convention that neither is an affinity predictor.
  • Boltz structural confidence is uniformly high (conf 0.74–0.87): the model predicts a plausible complex for every compound and does not discriminate within this series.
  • Boltz tier C holds the most potent compounds: c30 (5 nM, prob 0.014), c28 (22 nM, 0.035), c26 (21 nM, 0.103) all sit in the bottom tertile, while t02 (Takeda ~50 nM, 0.586) and c35 (600 nM, 0.549) top the probability ranking — the layer's binder probability does not follow potency.
  • Implication for the wet-lab benchmark: with both layers showing null correlation, the benchmark's value is not "which layer ranks potency" but (a) testing whether any layer-specific signal (e.g. per-series, per-binding-region) holds up experimentally, and (b) calibrating tier cutoffs on real EC50 data before either layer informs lead choice.

3 · Boltz-2 tier rule (computed)

  • Primary signal: affinity_probability_binary (Boltz-2's binder probability).
  • Tier assignment: data-driven tertiles of the 45-compound distribution — top tertile (prob ≥ 0.352) = A, middle (0.191–0.352) = B, bottom (< 0.191) = C; compounds with confidence_score < 0.5 downgraded one tier (none in this run — conf 0.74–0.87).
  • Supporting columns: confidence_score (structure confidence), ligand_iptm (interface quality).
  • Not a potency ranking — see §2: Boltz probability shows no correlation with EC50 and the most potent compounds (c30/c28/c26) sit in tier C. Wet-lab data (§4) is the only calibrator for any tier rule.

4 · Wet-lab benchmark plan

Goal

Calibrate the two computational layers (Vina docking score, Boltz-2 affinity probability) against measured hGPR81 EC50/Emax so future tier assignments rest on experimentally validated signals, not model assumptions.

Protocol (proposed)

  • Compound subset: full 45 if feasible, otherwise a stratified pick — all tier-A/B leads (c03,c04,c07,c10,c11,c26,c28,c29,c30,c38...) + boundary compounds + 4 reference ligands (CHBA, 3,5-DHBA, 3-OBA, lactate) as assay controls.
  • Assay: functional hGPR81 agonism (cAMP inhibition or β-arrestin), EC50 + Emax; GPR109A + GHS-R1a counterscreens for every measured analog.
  • Evaluation metrics:
    • Spearman rank correlation of each layer's signal vs log10(EC50) — global and within acyl-urea / constrained / amide series.
    • Tier confusion matrix: computed tier (A/B/C) vs experimental tertiles (potent ≤ 10 nM / moderate 10–100 nM / weak > 100 nM).
    • Partial-agonist flagging: does either layer separate full (Emax ≥ 80%) from partial (Emax < 60%) compounds? (c5–c8 are the natural test set.)
  • Threshold calibration: if a layer's signal correlates with EC50, derive operational cutoffs from the benchmark distribution; otherwise keep that layer as binding-mode evidence only (current convention for Vina).
  • Deliverable: this table updated with measured EC50/Emax + a benchmark summary section (correlations, confusion matrix, calibration plot).
